# @cafeverse/mobile — Native Mobile App

The mobile client for **CaféVerse**, built with React Native / Expo, TypeScript, Tailwind CSS, and Lucide icons.

## 🚀 Key Features

- Native mobile interface for table reservations, digital menu browsing, and customer portal.
- Responsive layout designed for Android and iOS phones.

## 💻 Commands

- `npm run dev` — Launch Vite/Expo web preview
- `npm run build` — Build web bundle
