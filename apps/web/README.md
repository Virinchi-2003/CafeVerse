# @cafeverse/web — 2.5D Animated Web Application

The web frontend for **CaféVerse**, built with React 18, Vite, TypeScript, Tailwind CSS, and Framer Motion.

## 🚀 Key Features

- **2.5D Visual Engine**: Floating dark chocolate pieces (squares, shards, cubes) and coffee beans with real-time mouse parallax depth physics.
- **Interactive Drink Showcase**: 2.5D hero presentation with animated steam and coffee selector.
- **Table Reservation Wizard**: Live availability slot checking, guest counters, and reference code generation.
- **Digital Menu**: Search, category filters, dietary tags, ingredient modals, and admin quick sold-out toggles.
- **Customer Portal**: Manage active and past bookings.
- **Admin Portal**: Table reservation approvals, seating management, menu CRUD, and audit logs.

## 💻 Commands

- `npm run dev` — Start local Vite server at `http://localhost:3000`
- `npm run build` — Typecheck and build production bundle into `dist/`
- `npm run preview` — Preview production build locally
